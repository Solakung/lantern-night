# ใต้แสงโคม (Beneath the Lanterns)

### ▶ [เล่นเลย](https://solakung.github.io/lantern-night/)

**ใต้แสงโคม** เกมแนวจีบสาวที่จะพาคุณสวมบทเป็น "ภูมิ" นักศึกษาที่ย้ายมาเรียนวิทยาลัยศิลปะบนเกาะวาริน เกาะเล็กๆ กลางทะเลที่มีเรือเข้าออกแค่วันละเที่ยว

บนเกาะแห่งนี้ มีสาวๆ น่าสนใจให้คุณทำความรู้จักมากถึง 5 คน

- **ใบบัว** เพื่อนสมัยเด็กสุดร่าเริง ที่ยังจำเรื่องวันวานของคุณได้ทุกเรื่อง
- **นีน่า** มือกีตาร์ปากแข็ง เก่งทุกอย่าง ยกเว้นยอมร้องเพลงให้ใครฟัง
- **ปราง** น้องปีหนึ่งขี้อาย ที่จำหน้าใครไม่ได้ ถ้าไม่ได้วาดเก็บไว้
- **มินตรา** ประธานสภานักศึกษาสุดเนี้ยบ ที่ทำงานหนักจนลืมดูแลตัวเอง
- **ฟ้าใส** บรรณารักษ์ใจดี ผู้คอยดูแลทุกคนที่เดินเข้ามาในห้องสมุด

คุณมีเวลา 12 สัปดาห์ก่อนถึง "คืนโคมทะเล" คืนที่เล่ากันว่า ใครได้ปล่อยโคมคู่กัน คำอธิษฐานจะเป็นจริง จะเลือกเรียน ทำงานพิเศษ หรือใช้เวลากับใคร ทุกอย่างอยู่ในมือคุณ

เกมเต็มไปด้วยโมเมนต์หวานๆ ริมทะเล ฉากเดตที่ทำให้ใจเต้น ความลับที่แต่ละคนซ่อนไว้ และทางเลือกที่จะพาไปสู่ฉากจบที่แตกต่างกันถึง 18 แบบ
